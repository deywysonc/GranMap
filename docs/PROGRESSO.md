# GranMap — progresso do pacote inicial (histórico)

> Documento preservado como registro do primeiro pacote. Para o estado atual,
> consulte `DEMO_VERTICAL_COMPLETA.md` e o README da raiz.

## Entregue neste pacote

### Aplicativo Flutter
- modelo tipado do mapa
- carregamento do JSON
- busca de POIs
- tela inicial
- próxima aula fictícia para desenvolvimento
- Navigation Engine
- algoritmo A*
- instruções básicas
- distância e tempo estimados
- visualização 2D esquemática da rota
- simulador de percurso
- estrutura `PositioningService` pronta para substituir simulação por sensores depois
- modelos iniciais do sistema colaborativo
- testes básicos

### Backend
- FastAPI
- SQLite local
- cursos
- professores
- salas
- ensalamento
- propostas de alteração de sala
- votação SIM/NÃO
- consenso inicial
- auditoria
- Swagger automático em `/docs`
- script de dados de desenvolvimento

### GranMap Admin
- React + TypeScript + Vite
- dashboard básico
- cadastro de cursos
- cadastro de professores
- cadastro de salas
- visualização de ensalamentos

- maquete 3D

- PDR real
