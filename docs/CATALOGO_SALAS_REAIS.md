# Catálogo real de ambientes — Gran Tietê

## Situação dos dados

**Reais:**
- nomes dos 27 ambientes;
- divisão em Corredor Colégio/Secretaria;
- divisão em Corredor Entrada Faculdade;
- identificação dos ambientes do Piso Superior.

**Provisórios até a planta arquitetônica:**
- posição X/Y/Z;
- ordem física das portas;
- distâncias;
- desenho dos corredores;
- localização das entradas;
- localização da escada;
- Nodes;
- Edges;
- rotas resultantes.

A geometria atual existe somente para manter busca, A*, mapa 2D e simulador funcionando durante o desenvolvimento.
